# ADR 0002: 年份价格合成一张表

**状态**：已接受
**日期**：2026-10-14

## 背景

进度里原计划分开设计 `rice_year_prices`、`shipping_rates`、`vacuum_rates`。对齐后，运费和真空包装费都是每年一个元/市斤数字，和米价、四档售价、每包斤数同一粒度。

## 决定

只建 `rice_year_prices`。一行一年，`year` 为主键。保存大米成本、运费、真空包装费、四档售价、每包斤数。九个字段都可独立填写，全部 `NOT NULL`，数值必须大于 0。毛利不入库。

不再建 `shipping_rates` 和 `vacuum_rates`。下一张业务表是 `orders`。

## 后果

### 正面

- 下单读价只查一行。
- 四档售价可以脱离「普通价 + 真空费」或「零售价 − VIP 下浮」单独修改。
- 毛利永远由当前行的售价和成本算出。

### 负面

- 运费或真空费若以后按地区、重量分段，本表要拆开或加新表，已有年份行要迁移。
- 同年中途改价会覆盖这一行。历史订单必须在 `orders` 里做价格快照。

## 替代方案

### A. 三张价目表

- 米价、运费、真空费分开，靠年份关联。
- 拒绝理由：三者都是一年一个单价，拆表没有额外规则，下单要读三行。

### B. 售价由公式生成

- 只存成本、运费、真空费、一档基准售价和 VIP 下浮。
- 拒绝理由：售价关系被写死，手填的四档价格无法各自偏离公式。
