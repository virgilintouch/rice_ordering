# ADR 0003: 订单采用关联 + 收货快照 + 价格快照

**状态**：已接受
**日期**：2026-10-22

## 背景

客户、地址、年份价格已落地。订单需要记下「谁买、发哪、卖哪一档价、当时收多少」，并且客户改地址、价目改价后，历史订单仍可读、仍可对账。

## 决定

建一张 `orders`：

1. **关联** `customer_id`、`address_id`、`price_year`，便于回查档案与价目。
2. **收货快照** 保存 `recipient_name`、`recipient_phone`、`address`。展示与发货以快照为准。
3. **价格快照** 保存选用售价、成本、运费、真空费、每包斤数、包数与 `amount`。改 `rice_year_prices` 不回写订单。
4. **状态** 仅四档：`ordered` → `paid` → `shipped` → `delivered`。暂无 `cancelled`。
5. **毛利不入库**，用快照计算。普通包装的 `vacuum_fee_per_jin` 记 0。

## 后果

### 正面

- 历史订单金额、收货信息稳定。
- 仍能按客户、年份价目做聚合。
- 状态机简单，适合本地台账。

### 负面

- 下单要同时写关联与快照，应用层需一次事务。
- 暂无取消态；误单只能备注或后续加迁移。

## 替代方案

### A. 只存外键，不存快照

- 拒绝理由：改地址、改价后历史单失真。

### B. 状态含 cancelled

- 暂不采纳。用户明确当前不需要。
