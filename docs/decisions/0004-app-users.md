# ADR 0004: 后台账号与客户档案分离

**状态**：已接受
**日期**：2026-10-22

## 背景

管理后台需要「用户管理」和登录。现有 `customers` 是买米客户，不是系统操作员。

## 决定

新建 `app_users` 表存放后台账号。字段：用户名、密码哈希、显示名、角色、状态、最近登录时间、创建/更新时间。

角色先两档：`admin`、`operator`。状态：`active`、`disabled`。密码只存哈希。

不把系统用户塞进 `customers`。

## 后果

### 正面

- 客户数据与登录权限互不污染。
- 后续做登录拦截、按角色隐藏菜单有挂载点。

### 负面

- 多一张表；首个管理员需手工或种子脚本写入。

## 替代方案

### A. 复用 customers

- 拒绝理由：买米客户与操作员语义不同；客户没有登录密码字段。
